Official metadata and both split lists were readable and passed structural checks. The official originals remain unchanged. Verified output copies and label manifests have been created under `nih_chestxray14/metadata/`.

**No final accuracy or other model metrics were calculated.** The project has only 1,537 of 25,596 official test images locally, and only 206 of the 1,454 saved prediction filenames belong to the official test list. The four downloaded source files were located in `nih_chestxray14/`, not in the expected `nih_chestxray14/metadata/`. The source files were read there and the requested metadata and test-list copies were made in `metadata/`. The README remains at its original location/name, `nih_chestxray14/README_CHESTXRAY.pdf`.

### Official metadata schema and quality

CSV columns, in source order:

`Image Index`, `Finding Labels`, `Follow-up #`, `Patient ID`, `Patient Age`, `Patient Sex`, `View Position`, `OriginalImage[Width`, `Height]`, `OriginalImagePixelSpacing[x`, `y]`

The source has **112,120 records**, **112,120 unique image filenames**, and **30,805 unique patient IDs**. There are zero missing values in all 11 columns, zero duplicate filenames, zero exact duplicate rows, zero invalid/non-numeric patient IDs, and zero missing findings. There are **20,796 multi-finding rows**. All finding tokens belong to the known NIH set of 14 findings plus `No Finding`; no unexpected tokens were found.

## Label rules and counts

Labels were generated by matching `Image Index` to image filenames, never by row position. The complete pipe-separated `Finding Labels` string is preserved as `original_findings`.

- Exact `Pneumonia` → `binary_label=1`, `class_name=PNEUMONIA`, eligible.
- Exact `No Finding` → `binary_label=0`, `class_name=NORMAL`, eligible.
- Every other label, including any multi-label annotation, → excluded with an explanatory reason.

Across all metadata records:

| Label outcome | Images |
|---|---:|
| Eligible exact Pneumonia | 322 |
| Eligible exact No Finding | 60,361 |
| Excluded other or multi-label findings | 51,437 |
| Total | 112,120 |

These counts deliberately exclude cases that contain Pneumonia together with another finding. The NIH findings are report-derived labels, not perfect clinical ground truth.

Although every prediction filename maps to metadata, most predictions are not from the official test split, and predictions cover only 206 of the 25,596 official test filenames. **Do not calculate final metrics from this prediction file.** The official test manifest makes membership and image availability explicit for all 25,596 official test entries.

## Generated files

- `nih_chestxray14/metadata/official_metadata.csv` — byte-for-byte copy of the downloaded official CSV; original retained separately.
- `nih_chestxray14/metadata/official_test_list.txt` — byte-for-byte copy of the downloaded official test list; original retained separately.
- `nih_chestxray14/metadata/verified_image_labels.csv` — one filename-matched label row for each of 112,120 official metadata records.
- `nih_chestxray14/metadata/verified_test_manifest.csv` — one row per official test filename, with genuine labels, official membership, local image availability, and any prediction matched by filename.
- `nih_chestxray14/metadata/label_exclusions.csv` — 51,437 excluded records with their original findings and reason.

`official_metadata.csv` and `official_test_list.txt` are copies; the downloaded source files, original images, model, and prediction files were not modified. No model training or fine-tuning was performed.
